# 龙岩放疗百科 V2

这是纯静态 HTML 版本，不依赖 Jekyll，因此 GitHub Pages 可以直接显示颜色和布局。

## 上传方法
1. 保留本地仓库中的 `.git` 文件夹。
2. 删除旧的 `_layouts`、`_posts`、`index.md`、`about.md` 和 `_config.yml`。
3. 把本文件夹内全部内容复制到仓库根目录。
4. GitHub Desktop：Commit → Push origin。
5. 等 Actions 绿色勾后，浏览器按 Ctrl+F5。

## 新增文章
复制 `articles/equipment.html`，重命名后修改标题和正文，再在 `index.html` 添加链接。
